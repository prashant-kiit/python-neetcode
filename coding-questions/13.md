Python provides these operations mainly for **sets**.

```python
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}
```

## 1. Union (`|`)

Elements present in **either** set.

```python
a | b
# {1, 2, 3, 4, 5, 6}
```

---

## 2. Intersection (`&`)

Elements common to **both** sets.

```python
a & b
# {3, 4}
```

---

## 3. Difference (`-`)

Elements in the **left** set but not in the right.

```python
a - b
# {1, 2}

b - a
# {5, 6}
```

---

## 4. Symmetric Difference (`^`)

Elements present in **exactly one** set.

```python
a ^ b
# {1, 2, 5, 6}
```

Equivalent to:

```python
(a - b) | (b - a)
```

---

## 5. Subset

```python
a = {1, 2}
b = {1, 2, 3}

a <= b   # True
a.issubset(b)  # True
```

Proper subset:

```python
a < b    # True
```

---

## 6. Superset

```python
b >= a   # True
b.issuperset(a)  # True
```

Proper superset:

```python
b > a    # True
```

---

## 7. Disjoint

Checks whether two sets have **no common elements**.

```python
a = {1, 2}
b = {3, 4}

a.isdisjoint(b)
# True
```

---

## 8. In-place Operations

```python
a = {1, 2, 3}
b = {3, 4}

a |= b    # Union update
# {1,2,3,4}

a &= b    # Intersection update

a -= b    # Difference update

a ^= b    # Symmetric difference update
```
